# はちみつスコーン レシピページ

GitHub Pagesでそのまま公開できる構成です。

## ファイル構成

- `index.html` — ページ本体
- `assets/` — レシピ写真・QRコード

## GitHub Pagesで公開する手順

1. GitHubで新しいリポジトリを作成します。
2. このフォルダ内の `index.html` と `assets` フォルダをリポジトリ直下にアップロードします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment** の Source を **Deploy from a branch** にします。
5. Branch を `main`、Folder を `/(root)` にして **Save** します。
6. 数分後に表示される GitHub Pages のURLを開きます。

`index.html` がリポジトリ直下にあるため、追加ビルドは不要です。
